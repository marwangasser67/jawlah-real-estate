# تحديثات لوحة تحكم جولة العقارية

## تشغيل التحديث

1. في Supabase افتح **SQL Editor → New query**.
2. افتح ملف `admin-features-migration.sql` وانسخ محتوياته إلى المحرر ثم اضغط **Run**.
3. ارفع الملفات المعدّلة من هذا التحديث إلى نفس مكان `index.html` في مستودع GitHub، ووافق على استبدال الملفات المتطابقة.
4. اترك ملف `supabase-config.js` الموجود في GitHub كما هو؛ لا تستبدله بالنسخة الموجودة في مجلد المصدر لأنها لا تحتوي على مفتاح مشروعك.
5. بعد اكتمال GitHub Pages، افتح الموقع وسجّل الدخول بحساب المدير.

## أين تجد الميزات؟

- **العملاء والطلبات:** يعرض بريد حسابات العملاء وطلبات الاهتمام بالعقارات.
- **إعدادات الموقع:** يغيّر الشعار وغلاف الصفحة الرئيسية، ويضيف روابط للقائمة، ورقم الهاتف وروابط واتساب وInstagram وX وSnapchat وFacebook.
- **تسجيل العملاء:** زر «إنشاء حساب جديد» في صفحة الدخول ينشئ حسابًا حقيقيًا عبر Supabase Auth.

كلمات المرور لا تُعرض في لوحة الإدارة ولا تُحفظ كنص مقروء؛ Supabase Auth يتحقق منها ويحميها. تظهر عناوين البريد الإلكتروني فقط.
