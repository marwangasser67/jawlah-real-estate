# Jawlah Real Estate Website

Responsive Arabic RTL real-estate website source.

## Source files
- `index.html` — page structure and Arabic copy
- `styles.css` — responsive layout and visual styling
- `app.js` — navigation, filters, map markers, property galleries, unit selector, and interest form
- `assets/` — Jawlah logo and property photography

## Run locally
Open `index.html` in a modern browser. No build tools or external libraries are required.

## Notes
- The Flutter Android app remains in the repository root under `lib/`.
- Website listing data and contact requests are demonstration data. Interest forms store locally in the browser and do not submit to a company server.
