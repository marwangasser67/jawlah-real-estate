# تفعيل لوحة تحكم جولة العقارية

## معنى الشاشة التي ظهرت في Supabase

المشروع حالته **Healthy**، وهذا يعني أن مشروع قاعدة البيانات تم إنشاؤه. ظهور **No repository connected** لا يمنع ربط الموقع؛ ربط GitHub اختياري لمتابعة تغييرات قاعدة البيانات. وظهور **No migrations** يعني أن جداول العقارات لم تُنشأ بعد.

## خطوات الإعداد مرة واحدة

1. في Supabase افتح **Project Settings → API Keys** وانسخ **Publishable key** (أو مفتاح `anon` القديم إن كان هذا ما تعرضه صفحة المشروع).
2. افتح `website/supabase-config.js` في GitHub وضع المفتاح مكان `PASTE_PUBLISHABLE_KEY_HERE`. رابط المشروع مضاف بالفعل من صورة Supabase التي أرسلتها.
3. من Supabase افتح **SQL Editor → New query**. انسخ محتويات `website/supabase-schema.sql` والصقها ثم اضغط **Run**. سيُنشئ ذلك جدول العقارات وجدول مديري النظام وسياسات الوصول ومخزن صور العقارات.
4. افتح **Authentication → Users** وأضف مستخدم المدير ببريد وكلمة مرور.
5. انسخ محتويات `website/supabase-schema.sql` إلى SQL Editor مجددًا، واستخدم آخر استعلام المعلّق أسفل الملف: أزل علامات `--` وضع بريد المدير بدل `admin@example.com` ثم شغّله. هذا يضيف الحساب لقائمة المدراء المسموح لهم.
6. احفظ `supabase-config.js` وبقية ملفات مجلد `website` في مستودع GitHub. بعد انتهاء نشر Pages افتح:
   `https://marwangasser67.github.io/jawlah-real-estate/admin.html`
7. سجّل الدخول بحساب المدير، ثم أضف العقارات. اجعل الحالة **منشور على الموقع** حتى تظهر للعامة. المسودة تبقى في لوحة الإدارة فقط.
8. لتشغيل حسابات العملاء وإعدادات الشعار والغلاف وروابط القائمة والتواصل، افتح SQL Editor وشغّل محتويات `admin-features-migration.sql` مرة واحدة بعد ملف `supabase-schema.sql`.
9. ارفع ملفات التحديث إلى GitHub Pages مع الإبقاء على `supabase-config.js` الموجود في المستودع؛ هذا الملف يحتوي على مفتاح الربط العام الخاص بمشروعك.

## أمان مهم

- المفتاح الذي يوضع في `supabase-config.js` هو **Publishable / anon key** فقط. لا تضع `service_role` أو `secret key` في GitHub أو في كود المتصفح.
- تفعيل Row Level Security وسياسات الصلاحيات جزء من ملف SQL؛ لا تحذفها. الموقع يستطيع قراءة العقارات المنشورة فقط، والإدارة المسجلة في `admin_users` تستطيع الإضافة والتعديل والحذف.
- لا تستخدم كلمة مرور حساب المدير نفسه في مكان عام، وفعّل المصادقة الثنائية لحساب GitHub وSupabase.
- كلمات مرور العملاء لا تظهر للمدير ولا يتم حفظها كنص في جدول الموقع؛ Supabase Auth يتولى التحقق منها. تظهر عناوين البريد الإلكتروني وتواريخ التسجيل في قسم **العملاء والطلبات**.

## البيانات الحالية

الموقع يظل يعرض عقارات المعاينة الموجودة في الكود إلى أن يتم إعداد المفتاح والجداول بنجاح. بعد الربط، يعرض العقارات المنشورة من Supabase بدل بيانات المعاينة. الصور تُرفع إلى Storage وتُربط تلقائيًا بالعقار.
